Notes

Please make sure all phone numbers everywhere on the site are consistent. They should all be formatted either like this: 987-654-3210 or like this (987) 654-3210 and should be the same everywhere on the site. Please make sure all phone numbers are click-to-call.

Please do not install any plugins or use any layouts or templates that we have not installed. If you feel you must install something other than what is already there, please contact us before you do.

Please make sure all the navigation link buttons are consistent across your design – the same size, shape, and color.

Please make sure that all header photos are “visible.” Please make sure when you use an overlay color that it doesn’t totally hide the image beneath it.

Please don’t delete the footer slide-in from the global footer. Even if you don’t do anything with it, we’re always going to use it in one format or another, and once it’s deleted, it’s difficult to re-install without having to re-do the entire global footer.

  • The Avanti theme has a default background image in many sections and rows. Delete it anywhere you find it.
  • When you are finished, please delete all unused pages and unused default images from the Avanti template.
  • The bottom copyright section should be: Content Copyright ©2026 Company Name | All Rights Reserved | Site Map
  • Link the Site Map to: {{temp_url}}sitemap.xml. Make the link the same color as the copyright text color.
  • Please make sure all phone numbers are click-to-call.
  • IMPORTANT: We have set the default heading and body text fonts. Please do NOT change them and please make sure that if you’re using layouts (sections/rows, etc.) you have saved from previous projects that you change them to the same fonts and sizes as the defaults.
  • Please make sure you do not use modules that have the font weight, size, etc. set in the module that overrides the global default settings and that would need to be edited individually instead of globally.
  • Please use your imagination and design skills to make every page on this site look great. Please use different “looks” for the sections – different background colors, patterns, photos, parallax photos.

The goal is to always make our sites look MUCH better than a client’s existing site. Thank you!
